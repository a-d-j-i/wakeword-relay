Wake Word Relay — Web Tools

Browser tools for microWakeWord-style INT8 TFLite wake word models.

🎓 Trainer

Train a wake word model entirely in the browser: TTS sample generation, augmentation, training and streaming INT8 TFLite export. Uses the microphone for live testing (requires HTTPS).

🧪 Emulator

Test an existing .tflite wake word model: load it, run WAV files or live microphone audio through the same audio frontend the ESP32-S3 firmware uses.
