How to build the bundle

Run once from the repo root:
python3 web_trainer/tools/build_noise_bundle.py \ --input_dirs /path/to/audioset_16k /path/to/fma_16k \ --output noise.bin
Requires the audioset_16k/ and fma_16k/ directories from train.py --downloads_dir. Output is ~100 MB; stored in OPFS (survives reloads, separate from IndexedDB).
